# Installation

1. PHP 8.3+ with pdo_mysql, curl, openssl, mbstring, json
2. MySQL 8+
3. DocumentRoot = `public/`
4. Open `/install` (7 steps) — imports `schema.sql` then `schema_part2.sql`
5. Remove or lock `install/` after finish
6. Admin: `/admin/login.php`
7. Merchants: `/merchant/apply.php`
8. Telegram webhook: `https://DOMAIN/telegram/webhook.php`
